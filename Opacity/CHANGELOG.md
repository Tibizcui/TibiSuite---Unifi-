# Changelog

## 7.1.5.15
- Premiere version d'Opacity, nouveau module de la suite TibiSuite : reglez l'opacite de n'importe quelle fenetre du jeu (Blizzard, TibiSuite et vos autres addons).
- Fondu au survol, profils par contexte (ABS, combat, raid, instance, monture), curseur maitre, prereglages Immersion et Raid, mode capture d'ecran qui reaffiche tout apres la capture.
- Pipette pour choisir une fenetre directement a l'ecran, liste "Ajouter" regroupee par addon.
- Export / import de profil par code texte, bouton Annuler apres un import ou un prereglage.
- Compatible ElvUI et EllesmereUI : leurs fenetres sont laissees tranquilles sauf si vous cochez "Forcer". Ne modifie jamais le mode Edition de WoW.
- Raccourcis clavier : curseur maitre +/- 10 %, capture d'ecran, pipette, activer / suspendre, fenetre.
